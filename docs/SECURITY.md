# 安全模型

一句话：**这个插件把「能在你电脑上跑命令的 dsh」暴露出去了。** 所以它的安全边界必须写清楚，
不能靠「反正是局域网的」这种假设。

## 威胁模型

| 攻击者 | 能力 | 我们怎么挡 |
|---|---|---|
| 同一个 WiFi 上的陌生人（咖啡馆 / 公司访客网） | 能扫到 `:3081` 并打开它 | 访问闸门：没有配对令牌一律 401。配对码 6 位 + 连错 5 次锁 5 分钟 |
| 相同网段的被动监听者 | 能看明文 HTTP | **挡不住**。要么用 Tailscale（WireGuard），要么在前面加 TLS 反代 |
| 公网上的扫描器 | 只有你主动拨中继时才有通路 | 中继默认只认房间令牌；房间密钥由 `secret` 派生，猜不到 |
| 中继运营者 | 看得到所有请求/响应明文 | **挡不住**（v0.1）。所以默认建议自建；路线图里有房间级 E2E 加密 |
| 拿到你手机的别人 | 手机上有配对令牌 | 令牌在浏览器 `localStorage`；建议开系统锁屏 + 浏览器密码库。发现丢失就删 `pocket.json` 里的设备或直接换 `secret` |

## 现状（v0.1）明确的取舍

1. **明文传输（HTTP）**。局域网内可用，公网必须套 Tailscale / Cloudflare Tunnel / 自己的 TLS 反代。
   这是有意的：在内网加自签证书会带来一堆「手机上点继续」的体验债，而且给人虚假的安全感。
2. **`?pocket=<token>` 会把令牌写进地址栏与浏览器历史**。它只用于「打开完整界面」这一跳，
   服务端立刻换成 `HttpOnly` cookie。共享设备上用完记得清历史。
3. **中继不解密、也不隐藏内容**。它是可信转发者。自建 = 你信任自己的机器。
4. **审批默认不接管**（`approvals: "observe"`）。改成 `"answer"` 等于让手机成为审批权威，
   请确认你知道「桌面 UI 也可能被手机抢先」这件事。
5. **PWA 的 localStorage 里放着长期令牌**（30 天 cookie + 本地 token）。不要把这个页面
   加到公共设备的书签里。

## 令牌与配对

```
secret        = 32 字节随机，落在 $DSH_HOME/pocket.json（0600）
配对码        = 6 位数字，每次启动/每次配对后轮换
token(device) = HMAC-SHA256(secret, "device:" + deviceId)
```

- 校验用常量时间比较（`timingSafeEqual`），不对长度/前缀提前返回。
- 配对码失败 5 次锁 5 分钟，锁定期内正确码也拒。
- 想一次踢掉所有设备：删掉 `pocket.json`（下次启动重新生成 secret），或删 `devices` 数组里那一条。

## 端口与暴露面

| 端口 | 绑定 | 谁该能连 |
|---|---|---|
| `3080`（dsh web） | `127.0.0.1`（**不要改**） | 只有本机 |
| `3081`（dsh-pocket） | `0.0.0.0`（可改 `bind`） | 你的手机 / 中继 |

**永远不要把 `dsh web` 自己绑到 `0.0.0.0`**，它的 `/api` 能跑命令。插件存在的意义就是
「不暴露上游、只暴露一层带闸门的窄口」。

`bind: '127.0.0.1'` + 中继或 Tailscale 是更保守的组合：本机之外的人连端口都扫不到。

## v0.2 新增暴露面（逐条写清）

| 能力 | 新增风险 | 默认状态 | 约束 |
|---|---|---|---|
| 内容同步（`session/follow`） | 手机能看到会话全文 | 开启 | 只有配对设备；只在你打开的会话上订阅；5 分钟没人看自动退订 |
| 断点续传 | 手机能往电脑写文件 | 开启 | 落在 `$DSH_HOME/pocket-uploads/`；单文件 512 MiB / 总量 2 GiB / 30 分钟回收；文件名去路径、禁隐藏文件 |
| 回环穿透 | 手机能访问电脑的**本机服务** | **关闭** | 只认 `loopPorts` 白名单；目标恒为 127.0.0.1；禁止指向插件自己；剥离手机的 cookie 与 Authorization |
| 诊断导出 | 可能泄内容 | 开启 | 只存事件码 + 数字（状态码/字节数/端口/条数），无聊天、无路径、无 IP、无令牌 |

回环穿透是这里最需要自觉的一条：一旦填了 `loopAny: true`，等于把电脑上所有监听 127.0.0.1 的服务
（数据库面板、调试端口、内部 API）交给手机。只在明确知道要什么时开，并优先用白名单。

## 建议的加固清单

```yaml
- id: dsh-pocket
  config:
    bind: 127.0.0.1        # 只让本机的隧道/中继拨进来
    approvals: observe     # 审批留在桌面，除非你确实要手机批准
    relayUrl: wss://…      # 公网一定用 wss，不要 ws
```

- 手机侧：把 PWA「添加到主屏幕」，用完退出浏览器标签。
- 中继侧：放在只跑这一个服务的容器里，`PORT` 从环境变量给，前面挂 TLS。
- 审计：插件把每次配对、每次 prompt/cancel 记到 dsh 的 stdout（`dsh-pocket: …` 前缀）。

## 不做什么

- 不实现「无需配对的免密访问」开关。
- 不把令牌写进 URL 以外的请求日志（`upstream.mjs` 只打印 cookie 前 16 字符）。
- 不在中继侧做任何业务判断（它不认识 `path` 的语义，只按 `id` 转发）。

## 报告问题

这是本地工具，没有服务器后端。发现安全问题请直接开 issue 并附复现步骤；
**不要**贴真实令牌与内网地址。
